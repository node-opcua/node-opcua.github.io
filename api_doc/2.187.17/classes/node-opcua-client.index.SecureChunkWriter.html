    Class SecureChunkWriter

    Chunks the messages of a secure channel (OPC 10000-6 6.7.2): the symmetric ones (MSG, CLO) of one token, and OpenSecureChannel with its asymmetric security header and RSA encryption. Everything that does not change between messages (chunk size, header layout, keys, block sizes, signature length, limits) is set once, and writing a message is one call, with no event and no per-message object besides the chunks.

    The body is encoded once, after room left for the headers. Each chunk then gets its own buffer (the transport keeps it; the encode buffer serves the next message), its headers, its slice of the body, and, as the channel's security requires, its padding, signature and encryption. One chunk is the n = 1 case of the same loop.

    A signature produced by a remote (HSM/KMS) provider is asynchronous: writeMessageAsync.
