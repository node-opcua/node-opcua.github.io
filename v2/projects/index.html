The node-opcua ecosystem

Beyond the main SDK, node-opcua is part of a family of open-source modules and tools, all MIT-licensed and maintained by Sterfive.

Core libraries

  • node-opcua — The main client and server SDK.
  • node-opcua-pki — PKI and certificate management for OPC UA.
  • node-opcua-crypto — Certificate tools, encryption, and signature support.

Companion specifications

  • node-opcua-isa95 — ISA-95 extension for node-opcua server.

Tooling

  • opcua-commander — OPC UA client with a blessed (ncurses) terminal UI.
  • bench-opcua — Performance benchmarks for OPC UA servers.
  • node-opcua-sampleserver — A simple reference OPC UA server based on node-opcua.
  • node-opcua-htmlpanel — Small HTML panel for displaying monitored variables.

AI and integrations

  • node-opcua-modeler-mcp-server — MCP server for OPC UA information modeling, designed for AI agents building industrial automation models.

Related projects

  • node-wot-opcua-tools — Tools for bridging (node-)WoT and (node-)OPCUA.
  • node-opcua-sample — A simple OPC UA sample client demonstrating SDK usage.
